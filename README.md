ND Visualization Project
Этот репозиторий демонстрирует интерактивную визуализацию объектов в $n$‑мерном пространстве. Пользователь выбирает тип фигуры (гиперкуб или гиперсфера) и число измерений, после чего программа автоматически вращает фигуру и отображает её трёхмерную проекцию. Вращение и проекция реализованы как корректные ортонормальные преобразования, а визуализация выполнена в тёмной гамме с золотистыми рёбрами.
Возможности
	Выбор фигуры:
	Гиперкуб — генерируются вершины гиперкуба в координатах {-1,+1}^n. Другие варианты координат не предусмотрены.
	Гиперсфера — генерируются точки на поверхности n-мерной единичной сферы.
	Автоматическое вращение:
	Фигура непрерывно вращается в нескольких плоскостях, используя композицию плоскостных поворотов (Givens rotations). Параметры вращения задаются программой; пользователю не нужно выбирать угол или включать вращение вручную.
	Проекция в 3D:
	Для отображения используются ортонормальные базисы, полученные с помощью QR‑разложения. Если число измерений меньше 3, проекция автоматически дополняется нулевыми координатами для корректного отображения в 3D.
	Тёмная тема и окраска:
	Поверхность фигуры рисуется как непрерывная оболочка (Mesh3d), рёбра гиперкуба и поверхность обоих объектов окрашены в тёмно‑жёлтый цвет. Фон графика тёмный.
	Интерактивная визуализация:
	Визуализация строится с помощью библиотеки plotly, что позволяет вращать и масштабировать трёхмерную сцену мышью. На графике доступны кнопки «Play»/«Pause» для управления анимацией и ползунок кадров.
Быстрый старт
	Установите зависимости (желательно в виртуальной среде):
pip install -r requirements.txt
	Запустите приложение:
python main.py
	Следуйте инструкциям в терминале: выберите фигуру, задайте число измерений и (при необходимости) количество точек. Программа построит вращающийся объект и покажет его проекцию в 3D.
Структура проекта
visualization/
├── ndviz/
│   ├── __init__.py
│   ├── shapes.py       # генераторы вершин для гиперкуба и гиперсферы
│   ├── rotation.py     # вращения в n‑мерности (Givens rotations и их композиции)
│   ├── projection.py   # построение ортонормальной проекции
│   └── main.py         # пример использования внутри пакета
├── main.py             # основное CLI‑приложение
├── requirements.txt    # список зависимостей
├── README.md           # данное описание
└── projects.code-workspace  # файл рабочей среды VS Code (необязательно)
