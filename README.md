ND Visualization Project

Проект демонстрирует интерактивную визуализацию объектов в n‑мерном пространстве. Пользователь выбирает тип фигуры (гиперкуб или гиперсфера) и число измерений, после чего программа автоматически вращает фигуру и отображает её трёхмерную проекцию. Вращение и проекция реализованы как корректные ортонормальные преобразования: для проекции строится ортонормальный базис с помощью QR‑разложения (строки базиса ортонормальны, и проекцию получаем умножением на транспонированную матрицу). Визуализация выполнена в тёмной гамме с золотистыми рёбрами.

Автоматическое вращение

Фигура непрерывно вращается в нескольких плоскостях. Параметры вращения заданы по умолчанию, что обеспечивает плавную анимацию (~60 кадров/с). Пользователь не выбирает углы.

Тёмная тема и окраска

Объект отображается как непрерывная поверхность (Mesh3d), а ребра (для гиперкуба) и поверхность окрашены в тёмно‑жёлтый цвет. Фон графика — тёмный.

Интерактивная визуализация

Визуализация строится с помощью Plotly. Можно вращать и масштабировать график мышью. Предусмотрены кнопки «Play»/«Pause» и ползунок для управления анимацией.

Быстрый старт

Установите зависимости (лучше в виртуальной среде):

pip install -r requirements.txt


Запустите приложение:

python main.py


Следуйте инструкциям в терминале: выберите фигуру и задайте число измерений (для сферы можно указать число точек). Программа построит вращающийся объект и покажет его проекцию в 3D.

Дополнительные идеи

Реализовать другие фигуры: гипероктаэдр (простая сфера) или точечные облака из разных распределений.

Добавить веб-интерфейс с использованием Streamlit или Dash.

Расширить управление вращением: позволить выбирать пары координат и скорости или добавлять слайдер для времени.

Буду рад вашим улучшениям и предложениям!
