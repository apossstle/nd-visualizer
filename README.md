ND Visualization Project

Этот проект демонстрирует интерактивную визуализацию объектов в $n$‑мерном пространстве. Пользователь выбирает тип фигуры (гиперкуб или гиперсфера) и число измерений, после чего программа автоматически вращает фигуру и отображает её трёхмерную проекцию. Вращение и проекция реализованы как корректные ортонормальные преобразования: для проекции строится ортонормальный базис с помощью QR‑разложения. Визуализация выполнена в тёмной гамме с золотистыми рёбрами и плавной анимацией.

Автоматическое вращение
Фигура непрерывно вращается в нескольких плоскостях. Параметры вращения заданы по умолчанию, что обеспечивает плавную анимацию (~60 кадров/с). Пользователь не выбирает углы.

Проекция в 3D
Для отображения используются ортонормальные базисы, полученные QR‑разложением. Если число измерений меньше 3, проекция автоматически дополняется нулевыми координатами.

Тёмная тема и окраска
Фигура рисуется как непрерывная поверхность (Mesh3d), рёбра гиперкуба и поверхность окрашены в тёмно‑жёлтый цвет. Фон графика — тёмный.

Интерактивная визуализация
Сцена построена на Plotly: можно вращать и масштабировать график мышью. Доступны кнопки «Play»/«Pause» и ползунок для управления анимацией.

Быстрый старт

Установите зависимости (желательно в виртуальной среде):

pip install -r requirements.txt


Запустите приложение:

python main.py


Следуйте инструкциям в терминале: выберите фигуру и задайте число измерений (для сферы можно указать число точек). Программа построит вращающийся объект и покажет его проекцию в 3D.

Дополнительные идеи

Реализовать другие фигуры, например гипероктаэдр (простая сфера) или точечные облака из разных распределений.

Добавить веб‑интерфейс с использованием Streamlit или Dash.

Расширить управление вращением: позволить выбирать пары координат и скорости или добавить отдельный слайдер времени.

Буду рад вашим улучшениям и предложениям!
